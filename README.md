# Internomium-2
The second part of the 2D space shooter game made with Unity which is especially designed for mobile platforms.
You can [download the .apk file](https://github.com/Techcrafter/Internomium-2/releases) or you can [play the first Internomium online](https://techcrafter.github.io/Internomium) (not designed for mobile platforms).
